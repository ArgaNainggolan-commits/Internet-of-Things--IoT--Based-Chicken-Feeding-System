# Sistem Pemberi Pakan & Suplai Air Ayam Berbasis IoT

Sistem otomatisasi kandang unggas cerdas yang dirancang untuk mengoptimalkan manajemen pakan dan air minum secara mandiri, mengurangi intervensi manual, serta menjaga keteraturan asupan ternak.

## 🚀 Fitur Utama
* **Automated Scheduling:** Pengaturan waktu pemberian pakan presisi menggunakan modul waktu nyata (*Real-Time Clock*).
* **Remote Control & Monitoring:** Memungkinkan peternak memantau status ketersediaan pakan/air serta memicu pemberian pakan secara manual via aplikasi.
* **Sensor Level Detection:** Mendeteksi batas minimum wadah pakan untuk mencegah kekosongan suplai.

## 🛠️ Stack Teknologi
* **Hardware:** Mikrokontroler, RTC (DS3231), Servo/Stepper Motor Driver, Sensor Level Cairan/Pakan.
* **Bahasa Pemrograman:** C / C++ (Embedded), Python/Web Dashboard untuk kontrol aplikasi.
